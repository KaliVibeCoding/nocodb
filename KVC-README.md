## KVC Integration

- Connected to KVC's Cloudflare D1 for edge-replicated databases
- Branded with KVC Neon-Noir theme via `kvc-brand.css`
- Import `kvc-brand.css` in `packages/nc-gui/assets/style.css`
- Use as internal CRM, contact DB, and student roster for KaliVibeCoding programs

## Quick Start
```bash
git checkout kvc-brand
# Apply brand CSS
echo '@import "../../../kvc-brand.css";' >> packages/nc-gui/assets/style.css
pnpm install && pnpm run dev
```
